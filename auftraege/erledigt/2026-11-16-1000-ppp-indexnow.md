Andre hat die Website photovoltaikperformancepro.com freigegeben (online seit 16.11.2026). Jetzt sollen Suchmaschinen sie finden. Bing, Yandex, Seznam und Naver werden über IndexNow benachrichtigt, das braucht kein Konto.

1. Die Schlüsseldatei `projekte/ppp/stufe1/website/5be86264736beec575350deb0aa9c40b.txt` nach `/var/www/eid/ppp-public/5be86264736beec575350deb0aa9c40b.txt` kopieren (nur diese eine Datei, sonst nichts an ppp-public ändern) und in `/var/www/eid` committen.
2. Prüfen: `curl -s https://www.photovoltaikperformancepro.com/5be86264736beec575350deb0aa9c40b.txt` liefert genau `5be86264736beec575350deb0aa9c40b`.
3. IndexNow benachrichtigen:
```bash
curl -s -o /dev/null -w "%{http_code}\n" -X POST https://api.indexnow.org/indexnow -H "Content-Type: application/json; charset=utf-8" -d '{"host":"www.photovoltaikperformancepro.com","key":"5be86264736beec575350deb0aa9c40b","keyLocation":"https://www.photovoltaikperformancepro.com/5be86264736beec575350deb0aa9c40b.txt","urlList":["https://www.photovoltaikperformancepro.com/","https://www.photovoltaikperformancepro.com/speicher/","https://www.photovoltaikperformancepro.com/impressum.html","https://www.photovoltaikperformancepro.com/datenschutz.html"]}'
```
   200 oder 202 = angenommen.
4. Prüfen, ob `https://photovoltaikperformancepro.com/` (ohne www) und `http://` jeweils mit 301 auf eine Adresse weiterleiten oder beide 200 liefern. Ergebnis nur melden, nichts an Nginx ändern.

# Abnahmekriterien

- Rückmeldung nennt den HTTP-Code von IndexNow und das Ergebnis aus Schritt 4.
